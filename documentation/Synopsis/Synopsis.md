# Synopsis

## Title
AI-Based Eye Disease Detection and Eye Care Recommendation System

## Introduction
The proposed system uses AI to detect common eye diseases from uploaded eye images and provide preliminary screening results with educational guidance.

## Problem Statement
Many users lack access to immediate eye screening services. Delayed detection can worsen outcomes. The proposed system provides an affordable preliminary screening tool.

## Existing System
Existing eye diagnostics are often expensive, require specialist visits, and are not easily accessible to all users.

## Drawbacks
- High cost
- Limited access
- Delayed diagnosis
- Lack of awareness

## Proposed System
A web-based AI system that accepts eye images, predicts probable diseases, provides confidence scores, and offers education and recommendations.

## Objectives
- Detect eye diseases from images
- Provide confidence-based results
- Support educational guidance
- Offer chatbot and doctor recommendation support

## Scope
The system covers image upload, prediction, explanation, and preliminary recommendations.

## Technologies Used
Python, Flask, TensorFlow, Keras, Pillow, NumPy, and frontend web technologies.

## Expected Output
The system will provide a disease prediction result with explanation and guidance.

## Conclusion
The project demonstrates the feasibility of AI-assisted preliminary eye disease screening.
